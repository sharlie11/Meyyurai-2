# Meyyurai Mobile App (React Native + Expo)

The official **React Native mobile application** for **Meyyurai — Safety, Rights & Guidance**.

---

## 📱 Features

1. **🚨 Emergency SOS & Helplines**
   - 1-Tap Emergency SOS button with haptic vibration & instant 112 dialing.
   - 24x7 Direct Helplines (1091 Women, 1930 Cyber Fraud, 1098 Childline, 14567 Elderline).
2. **⚖️ Know Your Rights Knowledge Base**
   - Comprehensive breakdowns of statutory rights (Women, Workers, Consumers, Cyber, Property, Child, Senior Citizens, Legal Aid).
   - Relevant bare act sections, BNS/IPC penalties, and complaint steps.
3. **🤖 Interactive AI Legal Assistant**
   - Plain-language legal guidance and action steps powered by AI.
   - Quick legal question chips and instant responses.
4. **🌐 Multi-Language Support (i18n)**
   - Instant language switching across **English, Tamil, Hindi, Telugu, Kannada, and Malayalam**.
5. **🔐 Supabase Auth & Safety PIN**
   - User authentication, emergency contact management, and safety PIN.

## 🚀 How to Run the App

### Prerequisites
- Node.js (v18+)
- Expo Go app installed on your Android/iOS phone (from Play Store / App Store)

### 1. Install Dependencies
Navigate to the `Meyyurai-Mobile` directory and install packages:
```bash
cd Meyyurai-Mobile
npm install
```

### 2. Start the Expo Dev Server
```bash
npx expo start
```

### 3. Open on your Phone
- Scan the QR code displayed in your terminal using the **Expo Go** app on your Android/iOS phone!
- To run directly on a connected Android phone over USB:
  ```bash
  npx expo run:android
  ```
